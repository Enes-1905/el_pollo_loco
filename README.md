# El Pollo Loco

El Pollo Loco is a browser-based jump-and-run game inspired by classic platform games.

The player collects coins and bottles, fights enemies and faces the final boss in an action-packed adventure.

## Features

- Character movement and jumping
- Multiple enemy types
- End boss fight
- Collectible coins and bottles
- Health and status bars
- Sound effects and animations
- Responsive gameplay experience

## Technologies

- HTML
- CSS
- JavaScript
- Object-Oriented Programming
